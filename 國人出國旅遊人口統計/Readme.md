## 國人出國旅遊人口統計視覺化

以 R 語言完成的資料視覺化專案，分析國人前往亞洲各國旅遊的人口結構，並以四種圖表類型呈現不同面向的洞察。

## 專案簡介

這個專案使用交通部觀光署 / 內政部移民署類型的出國統計資料，聚焦在國人前往亞洲主要國家（日本、中國、韓國、越南、泰國等）旅遊的人口結構，透過不同圖表類型回答不同問題：

| 圖表類型 | 想回答的問題 |
|---|---|
| 人口金字塔圖 | 各國旅客的年齡與性別結構如何？男女比例是否有差異？ |
| 圓餅圖 | 各亞洲地區旅遊人口佔整體的比例？ |
| 長條圖 / 群組長條圖 | 各地區 / 性別間的人口數量比較？ |
| 折線圖 | 月度旅遊人數的趨勢變化？ |

## 專案結構

```
.
├── 1221.csv              # 原始統計資料（Big5 編碼）

```

## 使用技術

- **語言**：R
- **套件**：
  - `ggplot2`：所有圖表繪製
  - `dplyr`：資料篩選與整理（filter、bind_rows）
  - `tidyr`：長寬表轉換（pivot_longer）
  - `reshape2`：資料重塑（melt）
  - `forcats`：類別重新排序（fct_reorder）
  - `stringr`：字串處理（str_c）

## 資料處理重點

- 以 `fileEncoding = "Big5"` 讀取中文編碼的原始 CSV 資料
- 使用 `na.omit()` 處理缺失值
- 將寬表資料（每個年齡組別分欄）轉換為長表資料，方便 ggplot2 繪圖
- 使用 `fct_reorder()` 依數值大小重新排序類別軸，讓圖表更易讀

## 圖表範例邏輯（人口金字塔）

```r
ggplot(data, aes(x = AgeGroup, y = Population, fill = Gender)) +
  geom_bar(data = data %>% filter(Gender == "男性"), stat = "identity") +
  geom_bar(data = data %>% filter(Gender == "女性"), stat = "identity", aes(y = -Population)) +
  coord_flip() +
  scale_y_continuous(labels = abs) +
  theme_minimal()
```

以正負值搭配 `coord_flip()`，讓男女兩側對稱呈現，是繪製人口金字塔圖的常見手法。

## 如何執行

1. 安裝必要套件：
   ```r
   install.packages(c("ggplot2", "dplyr", "tidyr", "reshape2", "forcats", "stringr"))
   ```
2. 將 `1221.csv` 放在工作目錄下
3. 依序執行各 `.R` / `.r` 檔案即可產出對應圖表
