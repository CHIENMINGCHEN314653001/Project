## 台灣人出國人數統計趨勢分析

以 R 語言完成的資料視覺化專案，分析民國 100 年至 112 年（2011–2023）台灣人出國統計資料，透過四種圖表類型呈現出國人數的季節性高峰、COVID-19 疫情衝擊，以及各洲別旅遊佔比趨勢。

## 專案簡介

本專案使用交通部觀光署類型的長期出國統計資料，橫跨民國 100 年至 112 年（13 個年度），從四個不同角度切入分析：

| 圖表類型 | 檔案 | 想回答的問題 |
|---|---|---|
| 長條圖 | `trip.r` | 各年度（100/102/104/106/108/110/112）每月出國人數的分佈與高峰月份？ |
| 面積圖 | `area.r` | 出國人數長期趨勢如何變化？疫情造成的影響有多明顯？ |
| 堆積柱狀圖 | `darea.r` | 各洲別（亞洲/美洲/歐洲/大洋洲/非洲）出國人數佔比逐年如何變化？ |
| 熱力圖 | `heat.r` | 用年份 × 月份的矩陣呈現，哪個時期出國人數最密集？ |

## 主要發現

- **季節性高峰**：出國人數高峰通常出現在 7-8 月暑假，第二波高峰在 10 月；1-2 月雖有過年假期，出國人數反而不如暑假。
- **疫情衝擊**：民國 109 年（2020）出國人數急遽下滑，對應 COVID-19 疫情爆發、各國尚無疫苗、邊境管制；民國 110 年起隨疫苗施打逐漸回升。
- **洲別分佈**：亞洲旅遊人數佔比遠高於其他洲別，其次為美洲、歐洲、大洋洲，最後為非洲，推測與地理距離、都市發展、流行文化、交通便利性等因素有關。
- **熱力圖驗證**：106 年前後的六、七月為出國高峰期，疫情發生後熱力圖明顯轉淡，對應出國人數的低迷期。

## 使用技術

- **語言**：R
- **套件**：`ggplot2`（所有圖表繪製）

## 資料處理重點

- 以 `fileEncoding = "Big5"` 讀取中文編碼的原始 CSV 資料
- 將原始資料逐列（洲別/年份）拆解並轉為數值向量，再重組為長表格式方便繪圖
- 使用 `rep()` 產生對應年份、月份、洲別的重複序列，對齊展開後的數值資料

## 圖表範例邏輯（熱力圖）

```r
ttyear = data.frame(
  year  = rep(100:112, each = 12),
  month = rep(1:12, times = 13),
  count = c(tt)
)

ggplot(ttyear, aes(x = factor(month), y = factor(year), fill = count)) +
  geom_tile() +
  scale_fill_gradient(low = "lightpink", high = "red") +
  theme_minimal()
```

以 `geom_tile()` 搭配年份、月份雙軸，將數值以顏色深淺呈現，適合觀察長期時間序列中的密集區間。

## 如何執行

1. 安裝必要套件：
   ```r
   install.packages("ggplot2")
   ```
2. 將所有 `.csv` 檔案放在工作目錄下
3. 依序執行 `trip.r`、`area.r`、`darea.r`、`heat.r` 即可產出對應圖表
